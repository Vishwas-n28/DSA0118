# DSA0118
Data Structures Using C – Linked List Implementations
Overview

This repository contains implementations of different Linked List operations in C as part of my Data Structures and Algorithms (DSA) practice.

All programs are written in simple C syntax and tested using an online compiler.
Each program demonstrates a fundamental operation on different types of linked lists.
